# Práctica 6 :)

En esta práctica desarrolle tres programas en Java utilizando Scanner para recibir y validar datos.

## Archivos

**PiInteractivo.java:** Calcula una aproximación de pi con la cantidad de dardos ingresada, **BinarioInteractivo.java:** Convierte números decimales a binarios y permite repetir conversiones Y **CabanaDelMisterio.java:&#x20;**&#x43;otiza préstamos con interés simple y compuesto, permite cambiar el capital y lleva un registro de operaciones y errores.

## Compilación y ejecución

Desde la carpeta `Practica06`:

**PiInteractivo**

```bash
javac -d bin src/PiInteractivo.java
java -cp bin PiInteractivo
```

**BinarioInteractivo**

```bash
javac -d bin src/BinarioInteractivo.java
java -cp bin BinarioInteractivo
```

**CabanaDelMisterio**

```bash
javac -d bin src/CabanaDelMisterio.java
java -cp bin CabanaDelMisterio
```

## Ejemplos

**PiInteractivo:** Se ingresan 1000 dardos y el programa muestra una aproximación de pi.

**BinarioInteractivo:** Se ingresa 67 y el programa devuelve 1000011.

**CabanaDelMisterio:** Con un capital de $12,899, tasa del 15% y plazo de 21 meses, calcula $3,385.99 de interés simple.
